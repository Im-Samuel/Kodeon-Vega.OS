Guía para navegación, reservas y gestión básica — Versión 1.0 (2025)

Para generar PDF: Ctrl+P (Windows) / Cmd+P (Mac) → Selecciona "Guardar como PDF". Para abrir en Word: abre este archivo (HTML) directamente en Word o copia el contenido.

1. Propósito

Este manual explica cómo usar el sitio del hotel: crear cuenta de cliente, iniciar sesión, realizar reservas y acceder al panel de administración básico.

2. Alcance

  • Usuarios finales (clientes).
  • Personal interno (Administrador, Recepcionista).
  • No cubre integración con backend ni servidores externos.

3. Requisitos previos

  • Navegador moderno (Chrome, Edge, Firefox, Safari).
  • Cookies y almacenamiento local habilitado.
  • No se requiere instalación: sitio estático.

5. Roles y permisos

Cliente
Puede registrarse, iniciar sesión, crear reservas y ver el listado.
Administrador
Inicia con credenciales predefinidas, ve todas las reservas y puede eliminarlas.
Recepcionista
Igual que Administrador para efectos del panel (gestión básica).
Nota: Los usuarios del personal están codificados en assets/js/Sesion.js.

6. Registro de clientes

  1. Ir a Registro.html.
  2. Completar ID, nombre y contraseña.
  3. Enviar el formulario: se almacena en localStorage.
  4. Ir a la página de inicio de sesión.

7. Inicio de sesión único

  1. Ir a LoginCliente.html.
  2. Ingresar "Usuario o ID" y contraseña.
  3. El sistema intenta primero como cliente registrado.
  4. Si no coincide, intenta como personal (admin / user).
  5. Si es correcto, redirige al panel de reservas.

Credenciales por defecto: admin / 123 | user / 456

Demo cliente: demo / 1234 (sembrado para pruebas).

8. Crear una reserva

  1. Ir a Reserva.html.
  2. Completar campos requeridos (nombre, teléfono, servicio, fecha mínima +2 días, hora, habitación).
  3. Enviar. Se guarda en el navegador (clave reservas).

9. Panel de reservas

Ubicado en reservas/panel.html. Exige sesión activa. Muestra todas las reservas guardadas localmente.

  • Clientes: solo visualización.
  • Personal: puede eliminar filas (gestión básica).

10. Avatar y menú

Tras iniciar sesión aparece un botón con iniciales (avatar). Al hacer clic despliega opciones: ir al panel y cerrar sesión.

11. Cerrar sesión

Desde el menú del avatar → "Cerrar sesión". Limpia la entrada hotel_auth de localStorage y vuelve a la pantalla de login.

12. Solución de problemas

  • No puedo iniciar sesión: Verifica credenciales, registra cliente si corresponde, limpia datos del sitio.
  • No veo botón Eliminar: Solo roles distintos de Cliente lo muestran.
  • No veo mis reservas en otro navegador: Se guardan localmente; no hay sincronización en la nube.

13. Seguridad y datos

Los datos no viajan a un servidor. Se almacenan en localStorage para demostración. No usar para datos reales sensibles.

14. Próximas mejoras sugeridas

  • Backend con API (Node/Express o similar).
  • Autenticación segura con hashing y tokens.
  • Filtro/búsqueda de reservas y paginación.
  • Exportación de reservas a CSV/PDF.
  • Roles adicionales con permisos granulares.
